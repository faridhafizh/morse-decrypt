# Security Policy

## Supported Versions

The following versions of Morse Pro are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within this project, please send an e-mail to . All security vulnerabilities will be promptly addressed.

### What to Report

- Potential unauthorized access to Passkey data.
- Exploits in the camera scanning logic that could lead to crashes or data leakage.
- Any other security-related concerns.

### What NOT to Report

- General bugs that do not have security implications.
- Issues related to non-secure development environments (e.g., lack of HTTPS on localhost).

Please include a detailed description of the vulnerability and steps to reproduce it. We will acknowledge your report within 48 hours and provide a timeline for resolution.
